  DOCUMENTAÇÃO DO PROJETO
════════════════════════════════════════════════════════════════════════════════

hen-Zip é uma aplicação desktop feita com PySide6 para compactar pastas em
arquivos ZIP e extrair arquivos ZIP ou RAR diretamente para uma pasta escolhida.
Cada linha da interface representa uma operação, com origem, destino e ação.
Na extração, o usuário pode escolher individualmente quais arquivos existentes
serão substituídos. Caminhos inseguros dentro de arquivos ZIP são rejeitados.

────────────────────────────────────────────────────────────────────────────────
MÓDULOS E RESPONSABILIDADES
────────────────────────────────────────────────────────────────────────────────

_CONFIGURA_/
  Fonte única de verdade para hardcodes. Cores, atalhos, dimensões, strings
  de UI. Nenhum outro arquivo pode ter valores fixos.

_LOGS_/
  Logger singleton. Gera LOG_GERAL.log a cada sessão.
  Captura crashes Python (sys.excepthook) e nativos C/Qt (faulthandler).

_APPDATA_/
  Gerencia a pasta do usuário no sistema (%APPDATA% / ~/).
  Caminhos canônicos, config.json, sessao.json.

_THREADS_/
  Base class ThreadSegura e gerenciador central ThreadManager.
  Todas as threads do projeto herdam ThreadSegura.

_APP_/
  Janela principal e toda a interface gráfica.
  Painel_operacoes contém as linhas de origem/destino, divisórias de grupo,
  reordenação por arraste/setas e o diálogo de conflitos.
  O botão e o menu Ajuda abrem o guia completo de uso.

_ULTILIDADES_/
  Ícones, popups e ferramentas reutilizáveis.

_ZIP_/
  Compactação ZIP, extração segura de ZIP/RAR, identificação de conflitos e
  worker em thread.

nucleo/
  Apenas documentação .txt. NUNCA coloque .py aqui.

────────────────────────────────────────────────────────────────────────────────
DECISÕES DE ARQUITETURA
────────────────────────────────────────────────────────────────────────────────

  A compactação grava o conteúdo da pasta de origem na raiz do ZIP, sem
  adicionar uma pasta externa com o nome da origem.
  O campo opcional de senha cria arquivos ZIP com criptografia AES-256; a senha
  digitada para extrair não é salva nas configurações.
  A extração mantém arquivos não selecionados no destino e permite substituir
  individualmente os arquivos marcados pelo usuário.
  No destino informado, se o ZIP tiver uma única pasta raiz com o mesmo nome
  do destino, esse nível é removido automaticamente. Quando os nomes forem
  diferentes, a opção "Remover raiz" controla se o nível é removido ou
  preservado. A cópia feita "Ao lado do arquivo" sempre mantém a pasta-raiz e
  mescla os arquivos nela quando a pasta já existe, sem aplicar "Remover raiz".
  ZIPs com mais de um item na raiz mantêm sua estrutura.
  A opção "Apagar ZIP após extrair" é salva por linha e só remove a origem após
  a conclusão bem-sucedida; o caminho permanece salvo.
  A conclusão emite um alerta; sua janela de informação fecha ao clicar fora e
  não bloqueia a interface.
  O botão Abrir logs abre LOG_GERAL.log; o resumo registra arquivos extraídos e
  arquivos mantidos sem substituição.
  A ordem das operações e as divisórias de grupo são persistidas em config.json
  via AppData e restauradas ao iniciar o aplicativo.
  Operações de arquivo rodam em ThreadSegura para manter a interface responsiva.
  A extração valida caminhos do ZIP e grava arquivos temporários antes de trocar
  arquivos existentes, reduzindo o risco de deixar arquivos parcialmente gravados.
  RAR é extraído via rarfile e requer UnRAR, Unar ou bsdtar. O UnRAR também é
  procurado na pasta padrão do WinRAR no Windows. Links e itens especiais
  encontrados em RARs são rejeitados. Cabeçalhos RAR criptografados exigem
  senha antes que a lista de arquivos possa ser lida e o pacote cryptography
  para descriptografá-los; senha incorreta, suporte de criptografia indisponível
  e arquivo RAR inválido devem gerar avisos distintos.
  Se o destino da extração ficar vazio e "Ao lado do arquivo" estiver marcado,
  o programa usa a pasta do arquivo compactado como destino único. Com destino
  preenchido, a opção também extrai uma cópia ao lado do arquivo, preservando
  e mesclando a pasta-raiz interna. A interface inicia cada operação recolhida,
  exibe o nome do arquivo sem extensão e expande os campos de caminho e senha
  em uma única linha para edição.

────────────────────────────────────────────────────────────────────────────────
DEPENDÊNCIAS EXTERNAS
────────────────────────────────────────────────────────────────────────────────

  PySide6       — framework Qt para Python
  qtawesome     — ícones FontAwesome/MaterialDesign para Qt (opcional)
  pyzipper      — leitura de ZIPs protegidos e criação de ZIPs AES-256
  rarfile       — leitura de arquivos RAR
  cryptography  — leitura de cabeçalhos RAR protegidos por senha
  zipfile       — biblioteca padrão do Python para manipular arquivos ZIP
  UnRAR, Unar ou bsdtar — ferramenta externa necessária para extrair RARs
